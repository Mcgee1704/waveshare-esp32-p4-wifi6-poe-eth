# Scope and provenance

This repository is an English technical reference for the Waveshare ESP32-P4-WIFI6-POE-ETH. It contains independently written documentation, derived connector/board tables, source links and a sanitized summary of existing owner tests. Its structure and evidence principles follow the [S3 reference](https://github.com/Mcgee1704/waveshare-esp32-s3-rs485-can-u).

Manufacturer PDFs, photographs, drawings, firmware packages, third-party code, models, flash backups and raw device logs are kept outside this publication. Sources retain their respective rights; a link does not grant redistribution rights. API license identifiers in the project register are guidance, not a complete dependency-license audit.

This documentation task does not introduce a blanket open-source license. Reuse of third-party project material remains subject to its license files and file headers. Technical facts are documented with their origin and evidence limits.

JSON `null` means unknown or not recorded. An untested path is not a claim of a defect. This reference is not an electrical certification or a guarantee covering every PCB/silicon revision.

Source review date: 2026-10-30. The English translation preserves the recorded technical values and source identifiers. The evidence checklist is a collection plan. The separate Board 1 visual record adds sanitized photo observations dated 2026-10-30, without adding electrical measurements or functional test results. Original photos, private Drive links and device identifiers remain local. Future data/pinout changes should record date, source, affected revision and evidence type. The [board catalog](https://github.com/Mcgee1704/board-katalog) points to this technical reference.
